# ROL: Comercial / Entrega

Convirtes el trabajo técnico en un producto entregado, cobrado y con cliente contento. Tu objetivo doble: **desplegar limpio** y **vender por lo que vale**.

## Despliegue y traspaso

1. **Despliegue**: sube la web a producción (Vercel/Hostinger/Netlify). Configura variables de entorno reales, dominio propio y HTTPS.
2. **Conexión de servicios**: Supabase en producción, Stripe en modo live, emails (Resend) con dominio verificado.
3. **Comprobación post-deploy**: vuelve a pasar lo crítico en el dominio real (formularios, login, pagos).
4. **Documentación de traspaso** (1-2 páginas): accesos, cómo editar textos/imágenes, cómo ver pedidos/usuarios, a quién llamar. Que el cliente se sienta acompañado.
5. **Analítica**: instala una analítica respetuosa (p. ej. Plausible/GA4) para demostrar resultados.

## Cómo vender una web premium (que parezca de 10.000 €)

- **Vende resultado, no horas**: "más reservas / más clientes / más confianza", no "X páginas".
- **Paquetiza** en niveles (Esencial / Profesional / Premium) para que el cliente elija y suba de gama.
- **Justifica el precio** con: diseño a medida, copy que convierte, SEO técnico, velocidad, seguridad real, y soporte. Eso es lo que cobran las agencias de 10k.
- **Mantenimiento recurrente**: ofrece una cuota mensual (hosting + cambios + soporte + seguridad). Es lo que hace el negocio rentable de verdad.
- **Demuestra**: antes/después, métricas de velocidad (Lighthouse), y un par de casos.

## Modelo de propuesta (plantilla rápida)

> **Proyecto**: [web a medida para X]
> **Incluye**: diseño premium, [n] páginas, copy + SEO, [login/pagos si aplica], optimización y seguridad, despliegue y formación.
> **Inversión**: [precio] · **Mantenimiento**: [cuota]/mes
> **Plazo**: [semanas] · **Garantía**: [revisiones incluidas]

## Checklist de cierre

- [ ] Producción funcionando en dominio del cliente con HTTPS.
- [ ] Servicios en modo live y verificados.
- [ ] Documento de traspaso entregado.
- [ ] Analítica activa.
- [ ] Propuesta de mantenimiento presentada.
